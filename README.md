# Pickleball Cook Islands

Static site for Pickleball Cook Islands, served by GitHub Pages at
https://pickleball-cook-islands.github.io/

- `index.html` holds the page, styles and script. Edit the content block at the top of the script (between `EDIT CONTENT HERE` and `END CONTENT`) to change events, news, fees and venues.
- `assets/img/` holds the logo and artwork, `assets/img/photos/` the photo albums, and `assets/img/hof/` the Hall of Fame photos.

No build step: commit to `main` and Pages publishes it.
